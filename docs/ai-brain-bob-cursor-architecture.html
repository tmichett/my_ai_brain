Known Gaps (Bob vs Cursor)

No session lifecycle hooks in Bob. Cursor auto-checks services at sessionStart and auto-backs up thoughts at sessionEnd. Bob has no equivalent. Workaround: activate the open-brain-preflight skill at session start; run ~/Github/my_ai_brain/scripts/backup.sh manually after significant sessions.
Bob only has 2 of 8 Cursor MCP servers. jira-mcp, github-mcp, slack-local, iterm-mcp, agentic-os-dashboard, and agentic-os-kanban are Cursor-only for now. Add to ~/.bob/settings/mcp.json if needed in Bob sessions.
No always-on MDC rules in Bob. Cursor's 14 alwaysApply rules run on every message. Bob relies on skill auto-invocation by description match — not guaranteed every turn.
